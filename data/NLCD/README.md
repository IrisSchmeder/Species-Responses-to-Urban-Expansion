# data/NLCD

NLCD 2024 Fractional Impervious Surface raster.

Expected file: `Annual_NLCD_FctImp_2024_CU_C1V1.tif` plus sidecars (.tif.aux.xml & .xml)
Source: https://www.mrlc.gov/data

The primary .tif file is too large to be hosted on github, so we've hosted it externally on Zenodo (https://zenodo.org/records/22309559)

Script 01_DataPrep.R includes a step to download the .tif + sidecars for use in downstream steps.

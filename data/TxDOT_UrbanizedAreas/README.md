# data/TxDOT_UrbanizedAreas

TxDOT urbanized-areas shapefile (not tracked in git).
Source: https://gis-txdot.opendata.arcgis.com/datasets/6aeee12f605d4b0b9fc74b31d2ea4ea5_0/about

Place the shapefile (+ sidecars) here. Note the two map scripts reference
slightly different filenames:
  - 09_TexasProvincesMap.R  -> Urbanized_Area.shp
  - 10_TexasImperviousMap.R -> TxDOT_Urbanized_Areas.shp
Use whichever your download provides and adjust the filename in the script
if needed.
